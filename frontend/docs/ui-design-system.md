# UI 设计基线

- 主色 `#2F54EB`，成功 `#36CFC9`，警告 `#FFB84D`，危险 `#E64398`。
- 正文 `#4B5563`，标题 `#111827`，提示 `#9CA3AF`，边框 `#E5E7EB`。
- 主字体采用系统中文字体栈；正文 16px，辅助 14px，标题 20～28px。
- 按钮/输入高度 44px，圆角 8px；卡片圆角 12px；弹窗圆角 16px。
- 页面最小宽度 1024px，设计宽度 1440px；侧栏 224/60px。
- 图表颜色顺序：蓝、青、橙、紫、粉；必须同时提供标签/Tooltip，不只靠颜色。
- 焦点可见、键盘可操作、表单有 label；对比度目标 WCAG AA。
- 视觉资产按正式设计系统复用，Font Awesome 大字体文件不内嵌，按需使用图标包。
