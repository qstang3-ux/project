# 经管之星前端需求文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 项目名称 | 经管之星——企业经营数据智能问数平台 |
| 文档类型 | 前端产品需求文档（FRD） |
| 版本 | v1.0 |
| 状态 | MVP 基线 |
| UI 基线 | 本文档与 `ui-design-system.md`，不复用历史原型业务代码 |
| 技术约束 | React + TypeScript |

## 2. 建设目标

前端为用户提供自然语言经营数据查询、结果解释、会话管理、模型与应用配置、错误反馈及回复校对能力。系统不实现登录和用户管理，默认使用后端配置注入的单一系统用户。

首版的核心目标是完整呈现以下真实链路：

> 提问 → 展示执行进度 → 查看 SQL → 查看真实查询结果 → 查看图表与总结 → 继续追问或提交反馈

## 2.1 交互处理原则

历史原型中的交互按以下规则进入正式需求：

- 当前页面可达且行为有效的交互，纳入 MVP。
- 当前页面可达但只是模拟实现的交互，保留用户体验并改为真实后端能力。
- 有完整代码但当前页面不存在入口的交互，不视为当前 UI 必须实现；与核心问数直接相关的数据源选择和问答日志作为产品能力补充纳入。
- 登录、退出、个人信息、用户、角色和权限管理按项目说明明确排除。
- 麦克风和语音播放使用零调用费的浏览器 Web Speech API 增强；识别文本只填入输入框，不自动发送，不支持时安全降级为文字交互。
- 驾驶舱、台账、报表、导入导出和账户管理等不可达遗留代码不纳入本期。

历史原型映射已归档于共享演示资料，不作为正式需求依据。

## 3. 技术及工程要求

### FE-NFR-001 技术栈

- 使用 React、TypeScript 和 Vite。
- 使用 React Router 管理页面路由。
- 使用 TanStack Query 管理服务端状态。
- 使用 Ant Design 或等价组件库构建基础组件。
- 使用 ECharts 展示查询结果图表。
- 所有后端数据必须通过统一 API Client 获取。
- 禁止在组件中散落后端地址或密钥。

### FE-NFR-002 目录和模块

前端至少按以下职责拆分：

```text
src/
├── api/              API Client 和请求类型
├── components/       通用组件
├── features/         按业务划分的功能模块
├── layouts/          主框架和侧边栏
├── pages/            路由页面
├── hooks/            通用 Hooks
├── stores/           必要的客户端状态
├── types/            共享类型
└── utils/            格式化、安全和辅助方法
```

### FE-NFR-003 浏览器支持

- 支持最新版 Chrome、Edge。
- 最低适配宽度为 1280px。
- 1024px～1279px 下页面仍应可操作，允许侧边栏默认收起。
- 不要求移动端完整适配。

### FE-NFR-004 安全

- 用户问题、模型回答、SQL 和数据库字段值必须按纯文本渲染或经过安全过滤。
- 禁止直接使用未经清洗的 `dangerouslySetInnerHTML`。
- API Key 输入框必须使用密码模式，接口返回时不得回显完整密钥。
- 前端不得把 API Key 保存到 localStorage、sessionStorage 或 IndexedDB。
- 错误提示不得展示后端堆栈、数据库连接串或密钥。

### FE-NFR-005 可用性

- 所有网络请求必须具有加载、成功、空数据和失败状态。
- 破坏性操作必须二次确认。
- 表单提交期间必须防止重复提交。
- 页面刷新后，路由和服务端已保存数据能够恢复。
- 长时间问数请求必须支持取消或停止展示。

## 4. 信息架构

主导航包含：

1. 智能问数。
2. 系统管理。
   - 应用配置。
   - 模型配置。
3. 反馈管理。
   - 回复校对。

建议路由：

| 页面 | 路由 |
|---|---|
| 智能问数 | `/qa` |

根路由 `/` 重定向到 `/qa`。

## 5. 全局布局需求

### FE-GLOBAL-001 顶栏

- 显示产品名称“经管之星”。
- 显示当前版本号。
- 可保留消息图标，但 MVP 不要求真实通知服务。
- 不显示登录入口。
- 不提供退出登录功能。
- 历史原型中的头像下拉、个人信息和退出登录不纳入实现；版本号改为非交互信息展示。

### FE-GLOBAL-002 侧边栏

- 显示当前范围内的菜单。
- 支持展开和收起。
- 收起后只展示图标和 Tooltip。
- 当前路由对应菜单必须高亮。
- 页面刷新后应保持收起状态，可保存非敏感 UI 偏好。

### FE-GLOBAL-003 全局错误处理

- 401/403：提示当前服务配置或访问权限异常，不跳转登录页。
- 404：展示资源不存在。
- 409：展示业务冲突信息。
- 422：展示表单校验信息。
- 429：提示请求过于频繁。
- 5xx：展示服务异常和请求 ID。
- 网络断开：提示检查网络并允许重试。

## 6. 智能问数

### FE-QA-001 欢迎页

- 新会话默认展示欢迎标题、开场白和推荐问题。
- 开场白及推荐问题读取应用配置。
- 点击推荐问题后，将内容填入输入框；用户确认后发送。
- 应用配置关闭开场白时，不显示开场白模块。

验收条件：

- 配置保存后，新建会话能够使用最新开场白和推荐问题。
- 无推荐问题时不显示空白容器。

### FE-QA-002 会话侧边栏

- 展示最近会话，默认按更新时间倒序。
- 置顶会话排在普通会话前，置顶组内仍按更新时间倒序。
- 支持创建、切换、置顶/取消置顶、重命名和删除会话。
- 会话项展示标题、更新时间或相对时间。
- 当前会话必须高亮。
- 支持侧边栏收起和展开。
- 数据超过一页时支持加载更多或分页。
- 置顶、重命名和删除通过会话项的更多操作菜单触发；点击菜单不得同时切换会话。
- 点击菜单外区域或按 Escape 应关闭更多操作菜单。

验收条件：

- 切换会话后展示对应消息。
- 删除当前会话后自动进入相邻会话；没有会话时进入欢迎页。
- 重命名不能为空，长度不超过 60 个字符。
- 删除操作必须二次确认。

### FE-QA-003 问题输入

- 支持输入自然语言问题。
- Enter 发送，Shift+Enter 换行。
- 空白内容不可发送。
- 输入长度默认限制为 2,000 个字符，并展示超限提示。
- 请求进行中禁止重复发送。
- 支持停止当前问数请求。
- 支持从快捷问题和推荐追问发起查询。
- STT 开启且浏览器支持时展示麦克风按钮，使用 `zh-CN` 做单次识别并把最终文本追加到问题框；用户必须确认后手动发送。
- 录音/识别期间展示明确状态，允许停止；权限拒绝、无麦克风、无语音、网络失败和能力不支持均给出可操作提示，不阻塞文字输入。
- 页面或组件卸载时停止识别，不保存录音或识别结果到浏览器持久存储。

### FE-QA-004 数据源选择

- 在输入区提供数据源选择入口。
- 数据源列表来自后端。
- 支持单选或多选，具体数量受后端能力约束。
- 默认选中后端标记的默认数据源。
- 数据源不可用时禁用并展示原因。
- 发送问题时必须明确携带已选数据源 ID。
- 数据源按“台账数据”“统计报表”或后端返回的分组展示。
- 支持全选、取消全选和逐项选择。
- 未选择任何数据源时禁止发送并提示用户选择数据源。

### FE-QA-005 消息展示

用户消息应展示：

- 问题文本。
- 发送时间。
- 复制。
- 收藏或取消收藏该问题。
- 编辑后重新发送。
- 使用原问题重新生成回答。

AI 消息应展示：

- 当前状态。
- 分析步骤。
- 最终自然语言回答。
- 生成 SQL。
- 数据结果表格。
- 图表。
- 执行耗时。
- 推荐追问。
- 复制和反馈操作。
- TTS 已启用时使用浏览器 `speechSynthesis` 和优先中文系统音色朗读回答，支持停止朗读；组件卸载时取消播放。
- 浏览器不支持 TTS 时按钮禁用并说明原因，不允许保留无响应按钮。
- `queued` 或 `running` 阶段在回答卡内展示轻量 Loading 和当前阶段提示；不得让用户面对空白回答卡。
- 本次新生成的回答完成后使用短时打字机效果展示正文；历史消息、刷新恢复以及系统启用
  `prefers-reduced-motion` 时直接展示全文，不重复播放动画。

### FE-QA-005A 编辑、重发与重新生成

- 用户可编辑已经发送的问题，并选择取消或重新发送。
- 取消编辑后必须恢复原文，不产生后端修改。
- 编辑后重新发送必须保留原始消息及执行记录用于审计，不允许直接覆盖历史记录。
- 对历史问题编辑后重发时，从该问题创建新的会话分支；新分支不自动删除原分支的后续消息。
- “重新生成”使用原问题、原数据源和当前有效上下文再次执行完整 Text2SQL 流程。
- 重新生成产生新的执行记录，并保留旧回答；界面默认展示最新版本，允许查看历史回答版本。
- 请求进行中，相关编辑、重发和重新生成按钮必须禁用。

### FE-QA-006 执行过程

前端通过 SSE 或等价流式机制接收状态，至少支持：

1. 正在分析问题。
2. 正在选择数据表。
3. 正在生成 SQL。
4. 正在校验 SQL。
5. 正在执行查询。
6. 正在生成回答。
7. 已完成。

每一步展示状态：等待、进行中、成功或失败。用户可以展开查看后端允许展示的步骤详情。

- 分析过程默认折叠，点击标题可展开或收起。
- 执行完成后步骤状态仍应可以查看。

不得展示模型完整内部思维过程；这里只展示可审计的系统执行步骤和摘要。

### FE-QA-007 SQL 查看

- SQL 默认折叠。
- 支持展开、复制。
- 使用等宽字体和 SQL 语法高亮。
- 展示 SQL 是否经过安全校验。
- 查询失败时展示经过脱敏的错误摘要。
- 不允许用户在 MVP 中直接编辑并执行 SQL。

### FE-QA-008 结果表格

- 表头来自后端返回字段。
- 支持横向滚动。
- 数字按照类型进行格式化。
- 空值统一展示为 `--`。
- 支持客户端排序或后端排序。
- 默认最多展示后端返回的有限结果集。
- 数据被截断时明确提示“仅展示前 N 条”。
- 支持导出 CSV；导出权限和行数限制由后端决定。

### FE-QA-009 数据可视化

- 根据后端返回的图表建议渲染图表。
- MVP 支持柱状图、折线图、饼图和指标卡。
- 无合适图表时只展示表格，不强制绘图。
- 图表必须展示单位、图例和 Tooltip。
- 图表配置异常时降级为表格，不影响答案展示。

### FE-QA-010 推荐追问

- AI 回答下方最多展示 3 条推荐追问。
- 点击后填充到输入框。
- 应用配置关闭该能力时不展示。
- 推荐问题为空时不展示容器。

### FE-QA-011 收藏和快捷问题

- 快捷问题面板包含“常问”和“收藏”。
- 常问数据来自后端聚合结果。
- 用户可以收藏或取消收藏问题。
- 收藏问题持久化到后端。
- 点击快捷问题后填入输入框并关闭快捷问题面板，不直接静默发送。
- 快捷问题面板支持显式关闭，并在点击面板外或按 Escape 时关闭。

### FE-QA-012 反馈

- AI 回答提供“数据有误”反馈入口。
- 反馈必须关联消息 ID 和执行记录 ID。
- 用户可选择原因：SQL 错误、结果错误、口径错误、回答错误、其他。
- “其他”原因允许填写补充说明，最多 500 字。
- 提交成功后展示成功提示并防止重复提交。

### FE-QA-013 问答日志

- 可从智能问数页面进入日志视图。
- 支持按时间、用户标识、状态和关键词筛选。
- 展示问题、模型、执行状态、耗时和发生时间。
- 点击日志进入详情，展示问题、数据源、SQL、结果摘要和错误摘要。
- 日志详情中的敏感字段必须由后端脱敏。
- 日志详情使用侧滑面板或等价层级展示，支持点击关闭按钮、遮罩或按 Escape 关闭。
- 支持复制日志 ID、用户问题和回答文本，并给予成功反馈。
- 从日志视图返回时恢复此前会话和滚动位置。

### FE-QA-014 异常状态

至少处理：

- 模型未配置。
- 模型连接失败。
- 问题与当前数据源无关。
- 无法生成安全 SQL。
- SQL 执行超时。
- 查询结果为空。
- 流式连接中断。
- 用户主动取消。

异常后应允许重新提问或重试，不得导致整个页面失效。

## 7. 模型配置

### FE-MODEL-001 模型列表

- 展示模型名称、供应商、模型标识、Base URL、启用状态和更新时间。
- API Key 仅在首次新增或用户主动选择“更换 API Key”时以空的密码输入框收集；保存后不再显示完整值或掩码。
- 支持新增、编辑、删除、测试连接和设为当前模型。
- 当前启用模型需要明显标识。

### FE-MODEL-002 模型表单

字段包括：

| 字段 | 必填 | 规则 |
|---|---|---|
| 配置名称 | 是 | 1～50 字符 |
| 供应商 | 是 | 预设或自定义 |
| Base URL | 是 | 合法 HTTPS URL；开发环境可允许 HTTP |
| 模型名称 | 是 | 1～100 字符 |
| API Key | 新增时是 | 编辑时默认完全隐藏；主动更换时重新输入 |
| 超时时间 | 否 | 1～120 秒 |
| 是否启用 | 是 | 布尔值 |

- 在模型选择框中选择“新增模型”时打开新增弹窗。
- 关闭或取消新增弹窗不应修改当前已选模型。

### FE-MODEL-003 连接测试

- 表单填写完成后可发起连接测试。
- 测试中展示加载状态。
- 展示成功或脱敏后的失败原因。
- 连接测试成功不代表自动保存。
- 未通过测试是否允许保存由后端配置决定；MVP 默认允许保存但给出警告。

### FE-MODEL-004 删除限制

- 删除操作需要确认。
- 当前正在使用的模型不能直接删除，应先切换模型。
- 后端返回冲突时展示明确原因。

## 8. 应用配置

### FE-APP-001 配置项

支持：

- 开场白启用状态。
- 开场白文本。
- 0～10 条推荐问题。
- 后续问题建议开关。
- 常问问题开关。
- 常问问题频次阈值。
- 模型问数开关。
- 浏览器 TTS/STT 功能开关；仅控制本机增强能力，不代表已配置云端语音服务。
- 推荐问题支持逐条新增和删除，达到 10 条时禁用新增按钮。
- 单条推荐问题为空时不得保存，单条长度不超过 100 个字符。

### FE-APP-002 保存行为

- 页面初始化时从后端加载配置。
- 修改后显示未保存状态。
- 保存成功后更新缓存。
- 离开存在未保存修改的页面时进行提示。
- 配置加载失败时不得用默认值静默覆盖服务端配置。

## 9. 回复校对

### FE-FB-001 反馈列表

- 展示反馈编号、用户标识、问题摘要、反馈原因、提交时间和状态。
- 支持按问题关键词、用户标识、原因、状态和时间筛选。
- 支持分页。
- 默认按照提交时间倒序。

### FE-FB-002 反馈详情

详情展示：

- 用户问题。
- 数据源。
- AI 回答。
- 生成 SQL。
- 查询结果摘要。
- 使用模型。
- 执行时间和耗时。
- 用户反馈原因与说明。
- 当前处理状态和处理备注。

### FE-FB-003 处理反馈

- 状态包括待处理、处理中、已解决、已忽略。
- 支持填写处理备注，最多 2,000 字。
- 保存后刷新列表及详情。
- 并发修改冲突时提示刷新数据后重试。
- 处理弹窗支持取消、保存、点击遮罩或按 Escape 关闭；存在未保存内容时关闭需提示。

## 9.1 通用弹窗与菜单行为

### FE-OVERLAY-001 弹窗

- 所有弹窗均提供明确标题和关闭入口。
- 取消或关闭不得保存修改。
- 确认按钮提交期间禁用。
- 可安全取消的弹窗支持点击遮罩和按 Escape 关闭。
- 存在未保存修改时，关闭前进行提示。

### FE-OVERLAY-002 复制反馈

- 复制成功后图标或文案短暂变为“已复制”。
- 剪贴板不可用时展示失败提示。

## 10. API 对接清单

前端依赖以下后端能力，最终以 OpenAPI 为准：

| 模块 | 能力 |
|---|---|
| 数据源 | 列表、默认数据源 |
| 会话 | 新建、列表、详情、更新、删除、置顶 |
