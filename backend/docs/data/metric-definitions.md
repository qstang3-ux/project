# 指标口径 v1.0

## 通用规则

- 数据币种：CNY；数据库金额：`numeric(18,2)` 元；UI 默认换算万元。
- 时间：数据库 UTC，业务统计按 `Asia/Shanghai` 自然日/月/季/年。
- 有效记录：`is_statistical=true` 且业务状态非取消/作废。
- 百分比保留 1 位；分母为 0 时返回空值，不返回无限值。

## 核心指标

| 指标 | 公式/口径 | 来源 |
|---|---|---|
| 商业目标 | 指定年度、经营单元的 `sales_targets.commercial_target_amount` | 目标表 |
| 商解目标 | 指定年度、经营单元的 `solution_target_amount` | 目标表 |
| 合同总额 | 有效合同 `contract_amount_tax_included` 求和 | 合同表 |
| 不含税合同额 | 有效合同 `contract_amount_tax_excluded` 求和 | 合同表 |
| 收入额 | 收入事实 `recognized_amount` 按确认日期求和 | 收入事实表 |
| 回款额 | 回款事实 `payment_amount` 按回款日期求和 | 回款事实表 |
| 已计收金额 | 截止统计日全部已确认收入之和，含往年合同 | 收入事实表 |
| 未计收金额 | 有效合同不含税金额 - 已计收金额，最小为 0 | 派生 |
| 已回款金额 | 截止统计日全部有效回款之和 | 回款事实表 |
| 未回款金额 | 合同含税金额 - 已回款金额，最小为 0 | 派生 |
| 应收金额 | 已计收含税金额 - 已回款金额，最小为 0 | 派生 |
| 目标完成率 | 收入额 / 商业目标 × 100% | 派生 |
| 商解完成率 | 商业解决方案产品线收入 / 商解目标 × 100% | 派生 |
| 同比 | (本期值 - 上年同期值) / 上年同期值 × 100% | 派生 |
| 环比 | (本期值 - 上一相邻周期值) / 上一周期值 × 100% | 派生 |
| 项目数量 | `mart.v_pipeline_risk` 中 `project_id` 去重计数；不得以合同数量替代 | PPL |
| 项目风险等级 | 三类风险取最高等级：高 > 中 > 低 | PPL |
| 常问问题 | 近 30 天成功问题标准化后计数 ≥ 配置阈值 | 问答日志 |

## 时间解释

- “今年/本年”：当前业务时区所在自然年；固定验收数据的分析年度为 2026。
- “本月”：指定统计截止日所在月；固定验收数据截止日为 2026-05-31。
- “Q1～Q4”：自然季度。
- 未提供年份且无法从上下文唯一确定：不得静默补默认年份，应通过澄清流程要求用户补充；“今年/本年”等明确相对时间仍按业务时区解释。
- “截至目前”：使用数据源 `data_as_of`，而非服务器当天时间。

## 维度定义

- 经营单元：承担目标与业绩归属的最小组织。
- 行业：客户业务领域；行业大类与行业为父子关系。
- 产品线：通用计算、智能计算、商业解决方案。
- 最终客户：实际使用产品或服务的客户；买方可能是渠道或集成商。
- 专项：经营分析标签，可一条合同关联多个专项。

## 歧义处理

- 用户说“销售额”：默认解释为不含税合同额，并在回答中说明。
- 用户说“业绩/达成”：默认解释为收入额和商业目标完成率。
- 用户说“商解”：解释为商业解决方案产品线。
- 用户在区域或行业枚举后附加“地区”“行业”等自然语言后缀时，按数据字典中的规范枚举值过滤，例如“华东地区”对应“华东”、“金融行业”对应“金融”。
- 无法唯一确定指标时，不猜测；返回可选口径并要求用户选择。
