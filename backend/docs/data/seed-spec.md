# 固定验收数据规格

## 规模

- 经营单元 21 个。
- 行业 8 个：金融、互联网、数字政府、智能制造、交通、医疗、教育、能源。
- 产品线 3 个，每条线 4～6 个型号。
- 客户 60 个。
- 2025/2026 年目标共 42 条。
- 合同 600 条；收入事实约 1,800 条；回款事实约 1,200 条；PPL 项目 180 条。

## 一致性约束

- 固定种子 `20260915`。
- 2026 数据截止日固定 `2026-05-31`，6～12 月收入不存在而不是 0。
- 每个合同金额、收入、回款保持：累计收入 ≤ 不含税合同额；累计回款 ≤ 含税合同额。
- 商业解决方案收入可用于商解达成率。
- 至少 5 个经营单元完成率低于 70%，至少 3 个高于 90%。
- 至少 15 个高风险项目、10 个空结果可验证组合。
- 2025 同期数据齐全，支持同比。

## 固定验收锚点

- 2026 商业目标前五：北京 7,950 万、上海 7,070 万、浙江 6,460 万、江苏 5,560 万、山东 4,090 万。
- 对应商解目标：1,200、980、860、720、650 万。
- Seed 生成后用 SQL 断言上述结果，防止后续数据漂移。

## 命令约定

```text
alembic upgrade head
python -m app.seed --seed 20260915
python -m app.seed --verify
```

`--seed` 幂等；已有同版本数据时不重复插入。`--reset` 仅允许开发/测试环境且需显式参数。
