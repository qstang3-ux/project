## 3. 原型交互与字段映射归档

### 3.1 原型交互处理原则

- 可达且有明确行为的问数、会话、配置和反馈交互纳入正式需求。
- 仅有视觉外壳而无行为的控件按产品目标重新设计，不照搬空交互。
- 登录、用户、角色、权限、驾驶舱、台账编辑和不可达报表不纳入当前范围。
- 麦克风和语音播放采用可配置的浏览器原生能力；不支持时回退文字交互。
- 数据源选择和问答日志虽非原型主入口，但因属于问数闭环而保留。

### 3.2 原型字段到正式模型

| 原型字段组 | 正式处理 |
|---|---|
| 合同主键 | `contracts.id`，使用 UUID |
| 卖方、签约主体 | `contracts.seller_name` |
| 行业 | `industries.major_name/name` |
| 产品线 | `product_lines.code` |
| 产品型号重复列 | 合并为 `contracts.product_model` |
| 经营单元 | `contracts.business_unit_id` |
| 合同编号、名称、签订日期 | `contract_no/contract_name/signed_at` |
| 买方、最终客户、客户级别 | 合同买方和 `customers` |
| 月度收入 | 拆分为多行 `revenue_facts` |
| 月度回款 | 拆分为多行 `payment_facts` |
| 季度、本年累计、应收 | 查询或语义视图派生 |
| 统计标记 | `is_statistical` |
| 专项 | `special_program` |
| 整体目标 | 映射到 `sales_targets`，万元转换为元 |

清洗规则：统一渠道名称；百分比转换为小数；空字符串转 `NULL`；日期统一 ISO；无法解析的记录拒绝入库；不使用原型运行时随机数。原型 `fields2026` 共 97 列、年度索引为 96，遗留代码读取 108 的行为不纳入实现。

## 4. 演示目标与讲解脚本

目标是在 6～8 分钟内说明平台可将自然语言转换为经过安全校验的只读 SQL，查询 PostgreSQL，并输出可追溯的结论、表格和图表，同时覆盖澄清、安全拒绝、导出和审计。

### 4.1 产品定位（约 40 秒）

系统面向经营分析人员。模型没有数据库直连权限；SQL 必须经过对象白名单、AST 校验、只读账号和执行超时控制。

### 4.2 主链路（约 2 分钟）

问题：`2026年商业目标最高的5个经营单元，用柱状图展示`

- 展示意图识别、知识召回、SQL 生成、安全校验、执行和答案验证。
- 展开 SQL，说明对象来自本次 RAG 召回与数据源白名单的交集。
- 展示答案要点、中文表头、表格与图表联动、CSV 和 PNG 导出。
- 点击继续探索建议，说明建议只回填，仍由用户确认发送。

### 4.3 主动澄清（约 1 分钟）

先问：`达成情况`。系统应进入待补充信息，而不是猜测 SQL。随后补充：`查询2026年各经营单元商业目标完成率，按完成率升序`。补充应在同一 execution 和 checkpoint 中继续，最多两轮。

### 4.4 安全拒绝（约 45 秒）

问题：`执行 SELECT 1; DROP TABLE mart.contracts`。系统应拒绝执行，危险请求不得进入数据库查询节点。

### 4.5 可追溯与修正（约 1 分钟）

- 编辑历史问题并重新发送，展示新分支保留原审计记录。
- 重新生成回答并查看版本链。
- 提交数据反馈，在回复校对页查看。
- 在问答日志展示 Request ID、意图、规范问题、SQL、Token、LangGraph、checkpoint 和 RAG 证据。

## 5. 演示问题集合

核心问题：

1. `2026年商业目标最高的5个经营单元，用柱状图展示`
2. `北京代表处2026年1到5月收入趋势，用折线图展示`
3. `2026年商业目标完成率低于70%的经营单元`
4. `2026年各产品线收入占比，用饼图展示`
5. `2026年行业收入排名`
6. `2026年收入同比情况`
7. `目前有多少高风险项目`
8. `应收金额最高的10个合同`

危险请求至少覆盖多语句、DDL/DML、越权 Schema、系统表和提示注入五类。

## 7. 异常与现场恢复

- 模型超时：展示已有完成记录和日志，不切换 Fake 模型冒充结果。
- 浏览器语音不可用：继续文字输入，并说明其依赖浏览器能力。
- 图表异常：保留表格作为可靠降级。
- SSE 中断：使用事件游标重连，达到上限后以执行详情轮询恢复。
- 容器无法现场启动：使用已通过健康检查的服务并展示配置，不声称完成未实际执行的容器验收。
- 预先准备一条完成态问答记录、日志详情、架构图和测试结果。
