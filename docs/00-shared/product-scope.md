# 产品范围基线 v1.0

## 目标

交付一个 React + FastAPI + PostgreSQL 的经营数据智能问数平台，真实完成自然语言到只读 SQL、查询、总结、图表、会话和反馈闭环，并可通过 Docker Compose 在 Linux 部署。

## P0（必须交付）

- 智能问数：数据源选择、会话、提问、SSE 进度、SQL、表格、图表、追问。
- Text2SQL：Schema 召回、生成、AST 校验、只读执行、一次纠错、结果总结。
- 真实模型 Agent：受控运行环境必须通过服务端配置的真实 OpenAI-compatible 模型完成 SQL 生成和结果总结；Fake Adapter 仅用于单元测试、CI 和显式本地离线开发。
- LangGraph 编排：使用有类型的状态图承载上下文装载、向量检索、SQL 生成、校验、执行、一次纠错、总结、核验和持久化。
- 向量 RAG：使用 PostgreSQL `pgvector` 检索 Schema、字段、指标口径、Join 关系和 Few-shot；关键词检索作为混合召回和降级路径。
- 消息操作：收藏、复制、编辑重发、重新生成、回答版本。
- 模型配置：CRUD、连接测试、启用；密钥后端加密/Secret 注入。
- 应用配置：开场白、推荐问题、追问、常问阈值、模型开关。
- 反馈校对：提交、筛选、详情、处理状态和备注。
- 问答日志：筛选、详情、SQL/耗时/错误审计。
- 固定验收数据、迁移、Seed、测试、评测、Docker、文档。

## P1（时间允许必须优先）

- CSV 导出（上限 10,000 行）。
- 查询取消、超时和断线恢复。
- 图表 PNG 导出。
- 备用模型切换。
- 零调用费浏览器语音：支持时使用 Web Speech API 将中文语音填入问题框，并使用设备音色朗读回答；不支持时安全降级为文字交互。

## P2（延期）

- 云端或自托管 STT/TTS 服务、流式转写和实时语音对话；浏览器原生语音能力不属于此延期项。
- Redis 缓存和复杂可观测平台。

## 明确排除

- 登录、用户、角色、菜单、权限、多租户。
- 驾驶舱、固定经营报表、台账导入编辑、审批流。
- 用户自由编辑执行 SQL、写数据库、生产高可用集群。

## 目标用户与身份

使用后端配置注入的单一系统用户；前端不能传入任意管理员身份。

## 发布成功标准

- 30 条评测集：SQL 可执行率 ≥95%，结果正确率 ≥90%，危险 SQL 拦截率 100%。
- 8 条核心评测问题成功率 100%，结果重复执行一致。
- 至少一次真实模型端到端冒烟通过，并保存供应商、模型名、Token、耗时和执行状态等脱敏证据；不得用 Fake 结果代替该验收。
- LangGraph 节点轨迹、条件分支和 checkpoint 可审计；同一执行最多一次 SQL 纠错。
- 向量知识库可重复构建，30 条评测问题的相关 Schema/指标 Top-5 召回率达到 100%。
- P0 自动化测试、构建、迁移和 Docker 健康检查通过。
- S0/S1/S2 缺陷为 0，无前端密钥、无危险 SQL 执行路径。
