# 验收场景 v1.0

## 核心验收场景

| ID | 操作 | 预期 |
|---|---|---|
| AC-01 | 新建会话，问“2026年商业目标最高的5个经营单元” | 安全 SELECT、5行降序表格、柱状图、结论一致 |
| AC-02 | 追问“它们的商解目标呢” | 正确继承前一问题的5个单元和2026年 |
| AC-03 | 问“北京代表处2026年1到5月收入趋势” | 月度折线图，缺月补0，单位明确 |
| AC-04 | 问“完成率低于70%的经营单元” | 正确关联目标和收入，按完成率升序 |
| AC-05 | 问“各产品线收入占比” | 仅三条产品线，饼图合计约100% |
| AC-06 | 编辑最后问题并重发 | 原执行保留，新分支/版本产生并显示新结果 |
| AC-07 | 对回答重新生成 | 新执行记录产生，旧回答版本可追溯 |
| AC-08 | 提交“口径错误”反馈并在校对页处理 | 反馈与消息、SQL、结果关联，状态成功更新 |

## 真实模型 Agent 验收

| ID | 操作 | 预期 |
|---|---|---|
| AGENT-01 | 在 `demo` 环境启动但未配置可用模型 | 问数失败关闭并返回 `MODEL_NOT_CONFIGURED`，不得静默降级为 Fake |
| AGENT-02 | 配置并启用真实 OpenAI-compatible 模型后提交核心问题 | 真实模型生成结构化 SQL，记录真实模型名、Token、耗时和状态 |
| AGENT-03 | 模型生成危险或越权 SQL | Agent 进入安全拒绝状态，SQL 不执行，也不得通过纠错绕过 |
| AGENT-04 | 查询执行出现可恢复的语法/字段错误 | 最多调用真实模型纠错一次，纠错结果重新经过完整 AST 校验 |
| AGENT-05 | 查询完成后生成回答 | 真实模型仅依据受限结果 JSON 生成结论、白名单图表和最多 3 条追问；后端验证字段和关键数字 |
| AGENT-06 | 真实模型超时、429、5xx、鉴权失败或返回非法 JSON | 有限重试、脱敏错误、Request ID 和审计状态正确，不泄露密钥或原始敏感响应 |

## LangGraph 与向量 RAG 验收

| ID | 操作 | 预期 |
|---|---|---|
| GRAPH-01 | 提交正常问题 | 执行按固定图经过 context、retrieve、generate、validate、execute、summarize、verify、persist 节点 |
| GRAPH-02 | SQL 出现可恢复错误 | 只进入一次 correct 分支，第二次失败直接结束，不形成无限循环 |
| GRAPH-03 | 进程在可恢复节点间中断 | 使用 execution/session 对应 checkpoint 恢复，不重复创建用户消息或执行记录 |
| GRAPH-04 | 用户取消或 SQL 被安全拒绝 | 进入明确终态，后续模型/数据库节点不再运行 |
| RAG-01 | 对 30 条评测问题执行召回 | 正确 Schema/指标文档全部进入 Top-5，记录排名和相似度 |
| RAG-02 | 更新指标或字段文档后重建索引 | 内容哈希变化的文档更新向量，未变化文档不重复写入 |
| RAG-03 | pgvector 或 Embedding 不可用 | `demo/prod` 返回明确错误；显式 local 模式可降级关键词召回并标记 degraded |
| RAG-04 | 检索内容包含 Prompt Injection | 作为不可信知识内容处理，不能改变系统安全规则、表白名单或工具权限 |

## 安全场景

| ID | 输入 | 预期 |
|---|---|---|
| SEC-01 | “删除所有订单” | 不生成/不执行写 SQL，返回只读限制说明 |
| SEC-02 | “SELECT 1; DROP TABLE...” | 多语句被 AST 校验拒绝 |
| SEC-03 | 要求查询 `app.model_configs` | 白名单拒绝，不泄露配置 |
| SEC-04 | 问题包含 HTML/脚本 | 作为纯文本展示，无脚本执行 |
| SEC-05 | 模型连接失败 | 前端获得脱敏错误，不包含 API Key |

## 页面验收

- 会话创建、切换、置顶、重命名、删除及侧栏收起可用。
- 快捷问题常问/收藏、复制、数据源选择可用。
- 执行步骤可展开，SQL 可复制，表格和图表能降级。
- 模型新增、测试、启用、删除限制符合需求。
- 应用配置保存后新会话立即生效。
- 反馈列表筛选、分页、详情和处理可用。
- 问答日志可筛选、查看详情和复制 ID。
- 开启浏览器语音能力后，支持语音识别的浏览器可将识别文本填入问题框且不会自动发送；回答可开始和停止朗读。不支持时明确提示并保持文字问答可用。

## 发布验收

- 干净 Linux 环境执行 Docker Compose 后健康检查通过。
- 迁移和 Seed 可重复执行；Seed 后核心问题结果固定。
- 前端 lint/typecheck/test/build、后端 lint/typecheck/test 全通过。
- 30 条评测达到范围文档目标；P0 缺陷清零。
- 真实模型冒烟报告包含供应商、模型名、执行 ID、Token、耗时和 8 条核心评测问题结果；Fake/Mock 测试报告单独列示。
- Agent 报告包含图版本、节点轨迹、checkpoint 状态、RAG 模型版本和召回评测结果。
